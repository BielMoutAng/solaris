# Solaris Biblioteca 0.1.1 - Windows

Arquivos para baixar no PC:

- `Solaris Biblioteca Setup 0.1.1.exe`: instalador recomendado. Cria atalho na area de trabalho e no menu iniciar.
- `Solaris Biblioteca 0.1.1.exe`: versao portatil. Abre direto, sem instalar.

As fichas ficam salvas no proprio computador. Para mover fichas entre PCs, use `Exportar` e `Importar` dentro do app.

Como o aplicativo ainda nao tem assinatura digital paga, o Windows pode mostrar aviso de seguranca. Isso e esperado em builds locais sem certificado.
