# Solaris Tabletop Alpha

Versao: 0.6.0-alpha.2

Arquivo principal para baixar e instalar no Windows:

- Solaris-Tabletop-0.6.0-alpha.2-Setup.exe

Esta build abre direto na Mesa Virtual/Tabletop, com servidor local embarcado quando instalada no PC. Ela inclui sala, jogadores, chat, rolagens, combate compartilhado, sincronizacao de ficha, mapa tatico, loja de sessao, loot, distribuicao e fichas de monstros.

Hash SHA-256:

- 06BDEA1C8A668F38596E0DAE47F9C222B02938FA55D3E0BBA5113B487FCC43E7

Para testar no PC, baixe o instalador, execute o arquivo `.exe` e abra o aplicativo instalado. Se o servidor local nao iniciar, o aplicativo ainda abre em modo offline/simulado para preservar a ficha local.
