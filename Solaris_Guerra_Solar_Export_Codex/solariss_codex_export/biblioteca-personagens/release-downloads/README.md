# Solaris Tabletop Alpha

Versao: 0.6.0-alpha.1

Arquivo principal para baixar e instalar no Windows:

- Solaris-Tabletop-0.6.0-alpha.1-Setup.exe

Esta build inclui a fase alfa da Mesa Virtual/Tabletop com servidor local opcional, sala, chat, rolagens, combate compartilhado, sincronizacao de ficha, loja de sessao, loot e distribuicao.

Para testar no PC, baixe o instalador, execute o arquivo `.exe` e abra o aplicativo instalado. Para testar a mesa em rede local, abra o app/servidor conforme a documentacao do projeto e use o modo Mesa Virtual.
